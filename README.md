# Barbearia dos Nerds

Site estático de uma barbearia fictícia, feito no curso técnico do SENAI (2022).
Primeiro projeto de site com mais de uma página.

**Ao vivo:** https://leocasteletti.github.io/site-barbearia/

## Páginas

- **Início:** apresentação, missão e benefícios
- **Produtos:** serviços de cabelo, barba e combo

## Stack

HTML · CSS

Fotos de bancos de imagem gratuitos, usadas apenas para fins de estudo.
